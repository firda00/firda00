## 🌟 Ключевые проекты (Showcase)

### 📞 [AutoCall Engine (Client-First Bridge)](https://github.com/firda00/autocall-demo)
> **Технологии:** Node.js (>=22), Server-Sent Events (SSE), onlinePBX API, SIP Bridge, Tailwind CSS  
- Автономный движок умного автообзвона с интерактивной веб-панелью.
- **Client-First Manager Bridge**: звонок сначала дозванивается до клиента и в ту же секунду соединяет его с персональным закреплённым менеджером по внутреннему номеру ATS.
- Защита от сбросов (звонок не начинается, если менеджер не на смене), контроль рабочих часов, суточные лимиты, интеллектуальный повтор и автоматическая эскалация в Telegram.

### 🤖 [Nemo AI Workforce OS](https://github.com/firda00/nemo-ai)
> **Технологии:** TypeScript, React, Supabase, Deno Edge Functions, LLM Providers, Vitest  
- Платформа координации автономных ИИ-сотрудников и мультиагентного выполнения задач.
- Контракты безопасности, очереди согласования, аналитика финансов и генерация интерактивных артефактов.

### 🎬 [Montazh AI](https://github.com/firda00/montazh)
> **Технологии:** TypeScript, Faster-Whisper, Piper TTS, Telegram Bot API, FFmpeg  
- Автоматизированный конвейер видеомонтажа, транскрибации речи, генерации субтитров и голосового дубляжа через Telegram-бота.

### 🔬 [AI & Applied ML Portfolio](https://github.com/firda00/chtoto-s-chemto)
> **Технологии:** Python, PyTorch, LangChain, Transformers, OpenCV, FastAPI  
- Коллекция практических прикладных ИИ-решений:
